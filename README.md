# proof-of-learning

Proofs of concept, experiments, and notes from things I'm building and learning,
from RAG pipelines and MCP servers to system design and full-stack patterns.

Built with Next.js (App Router), TypeScript and CSS Modules. Deployed on Vercel.

## Projects
- [mongodb-rag-mcp](https://github.com/deekshitha-a-20/mongodb-rag-mcp) — RAG on MongoDB Atlas Vector Search, exposed via MCP
- [mongo-mcp-server](https://github.com/deekshitha-a-20/mongo-mcp-server) — MCP server for MongoDB operations
- [playwright-ada-mcp](https://github.com/deekshitha-a-20/playwright-ada-mcp) — WCAG accessibility auditing via MCP

## Run locally
npm install
npm run dev
